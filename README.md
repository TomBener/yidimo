# 一滴墨

一张会呼吸的宣纸。打开它，一行古诗会自己落在纸上，墨渗进纸纹；用手指划过，墨在水里翻卷，每一笔都有琴声。

在线体验：<https://retompi.com/yidimo/>

## 能做什么

- **以指为笔**：在纸上划过，墨随水流翻卷、拖尾、晕开
- **诗**：随机落一行王维、李白、苏轼；**写**：写你自己的字
- **风**：整幅字像烟一样被吹散
- **墨 / 彩 / 星**：彩是朱砂、石青、石绿、藤黄等矿物色，混色像真颜料；星把纸变成夜空，墨变成流光
- **存**：把这幅画留下来（弹窗里长按或右键保存）
- 键盘：空格 = 风，P = 诗，C = 清，M = 换色

## 它是怎么做的

整张纸是一个 HTML 文件，五百余行，零依赖，没有一张图片、一个音频采样。

- **水**：墨的流动是显卡上实时求解的纳维–斯托克斯方程（WebGL2）：半拉格朗日平流、涡量约束、雅可比迭代解压力泊松方程
- **墨**：颜色按比尔–朗伯定律做减色混合，所以朱砂遇石青会变紫、淡墨泛青；纸纹、渗化、飛白都在着色器里生成
- **声**：琴音由 Karplus–Strong 弦振动模型当场合成，宫商角徵羽五声音阶
- **字**：Google Fonts 的马善政毛笔楷体，逐字盖印进染料场，再由流体带着渗化

## 本地运行

直接用浏览器打开 `index.html` 即可（需要支持 WebGL2 的浏览器）。
